## 二、正文（可直接复制，899 字）

写英文论文的人，Zotero 里都躺着几百篇 PDF。
最烦的不是读不懂，而是翻译在 A 软件、笔记在 B 软件，Zotero 里那份原文还是英文的。

最近在用 ReadPI（Windows 免安装），它把这条链路收进了一个窗口。

【Zotero 联动 · 这次最想推】
· 文献列表右键 / PDF 阅读器按钮 / 页面右键，三处都能「在 ReadPI 中阅读」
· 首次打开自动接入，不用导出再上传；应用没开着也会自动拉起
· 同一个附件只认一条记录：译文、笔记、批注、阅读位置全保留，第二次打开接着读
· 结果库直接读 Zotero 文库和嵌套文件夹，搜索、阅读、翻译都在里面
· 只复制副本，Zotero 原件一个字不动（也不写回，纯单向）

【AI 助读】选中原文右键「引用提问…」，回答里每个论断都带 p.N 出处，点一下跳回原文；文末还有「依据」列表。默认调用本机已登录的 Codex / Kimi / Claude CLI，不用填 Key。

【AI 帮写】笔记是独立悬浮窗，润色、学术化、精简、扩展、理结构、纠语病六个动作；先给「建议 / 对比 / 原文」，你确认了才写进正文，还能撤销。

【免费模型】Google 翻译（内置免费接口，不用 Key）、Ollama 本机跑、OpenRouter 上 :free 结尾的模型。想认真读再换 DeepSeek / GLM / Gemini / Kimi。

【界面重做】按 Apple HIG 重做了设置、结果库和阅读工具坞，深浅色跟系统；八色高亮、六种标记、页边距批注，批注能 Ctrl+Z。

【解压即用】ZIP 里内置 Python、BabelDOC、离线模型和字体，解压 → 双击 Start.bat，不用配环境。

坦白局：只有 Windows；免费接口会限流；双语同步按版面位置估算，不是逐句对齐；安装包未签名，Win11 可能拦一次。

GitHub 搜 ReadPI（PiDesign-314/ReadPI），Releases 下 Windows x64 ZIP，别下 Source code ZIP。

## 五、评论区置顶（建议发布后自己发一条）

```
补几个新手容易卡住的点：
1）安装包看文件名是 BabelDOC-Studio-Windows-x64.zip，别下 Source code ZIP，那是源码
2）Zotero 插件在「翻译设置 → Zotero 集成」里下载，Zotero 工具 → 插件 → 从文件安装，装完不用重启

5）Google 免费接口会限流，做正式精读建议换付费模型或挂术语库
```

## 六、发布前自查（事实边界）

- 版本口径统一为 **ReadPI 1.8.1 + Zotero 插件 1.0.6**，Zotero 需 **7 及以上**（插件声明 7.0–10.*）。
- 不要写成这些（文档不支持）：**Zotero 双向同步**（实为单向、不写回）、**逐句对齐**（按版面位置估算）、**免费无限**、**macOS 可用**、**双击即免拦截**、**一键翻译整个文库**（只有单篇入口）。
- AI 助读的「不用填 Key」指默认走本机已登录的 CLI；CLI 本身是否联网、是否占用订阅额度由它自己决定，别引申成「免费 / 离线」。
- 仓库暂无 LICENSE 文件，别写「开源」「可商用」。
- 配图里的论文是公开的 *Attention Is All You Need*（arXiv:1706.03762），笔记与批注是演示数据，不含任何个人文档。
- 如临近发布时仓库版本已推进到 1.9.x，把正文与封面里的版本号一并改掉再发。

事实核对明细见 `xiaohongshu/facts.md`；要改图直接改 `xiaohongshu/render_cards.py` 后 `python xiaohongshu/render_cards.py` 重出。
