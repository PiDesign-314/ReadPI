# ReadPI × Zotero｜小红书新版

## 现有版本最需要改的 3 件事

1. 主线被九项功能拆散，读者很难看到一次完整的阅读过程。
2. 产品截图占比太小，图中文字讲的操作无法在手机上看清。
3. 九页同一种排版和卖点句式，缺少「打开、阅读、再打开」的节奏。

## 标题（三选一）

1. 超好用的论文翻译工具，还能连接 Zotero 文献库（封面使用）
2. 论文翻译、阅读和笔记，连上 Zotero 文献库
3. 从 Zotero 打开论文，在 ReadPI 接着读

## 正文（可直接发布）

前阵子读一篇英文论文，最烦的不是某一句看不懂，而是读到一半停下来，过两天又要重新找 PDF、译文和笔记。我做 ReadPI，最想解决的就是这个「接不上」的问题。

现在我会先在 Zotero 里选中那篇有本地 PDF 的文献，右键点「在 ReadPI 中阅读」。第一次打开，ReadPI 会接入一份 PDF 副本，不用先导出再上传。需要翻译时，用我在 ReadPI 里保存的设置开始这篇论文的任务；完成后，我可以对着原文和译文读，在关键处做批注，把想法记成关联原文页的笔记。

下次还是从 Zotero 打开同一个附件，ReadPI 会回到这篇已有的阅读记录：译文、批注、笔记和上次读到的位置都还在。对我来说，这比多一个功能按钮更重要。

有两个边界也说清楚：目前只提供 Windows 10/11 x64 版本，Zotero 入口需要先安装 ReadPI 插件，且文献要有已下载的本地 PDF。联动是从 Zotero 读入 ReadPI；笔记和批注不会写回 Zotero，也不会改动 Zotero 原件。

想试的话，在 ReadPI 的「翻译设置 → Zotero 集成」下载插件，再到 Zotero「工具 → 插件 → 从文件安装」。项目与安装包在 GitHub 搜 **PiDesign-314/ReadPI**。这里的「ReadPI × Zotero」只表示我做的产品联动。

## 手机缩略图检查

- 300 像素宽预览下，五张图的大标题能读清，截图的关键区域比旧版明显更大；第 2 页的 Zotero 右键菜单仍缺真实截图，因此用明确的菜单文字说明，不能把 ReadPI 结果库冒充成 Zotero 菜单。
- 五页在深色封面、步骤页、全幅双语页、笔记特写、深色收束页之间切换，节奏不重复。
- 原始 `主体.svg` 与 `PI DESIGN.svg` 已从用户提供的路径复制到 `brand-original/`，导出时直接渲染这些矢量文件；形象和字标没有重绘或改色。
